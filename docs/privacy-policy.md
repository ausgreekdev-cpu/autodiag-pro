# Privacy Policy — AutoDiag Pro

**Effective date:** [set when publishing to the Microsoft Store]

AutoDiag Pro is an offline desktop application for OBD-II vehicle diagnostics.
It is designed to work entirely on your computer.

## Data the app stores (locally only)

All data stays in a local app-data folder on your device:

- Vehicle data read through the OBD-II adapter (VIN, diagnostic trouble
  codes, live sensor values, readiness monitors, UDS responses)
- Scan history and diagnostic logs you save
- Work-order details you type in (customer name, phone, mileage, job
  description, notes) — all optional
- Adapter/port preferences and app settings

## Data the app does NOT collect or transmit

- No accounts, no sign-in
- No telemetry, analytics, crash reporting, or advertising
- No cloud services — the app works with networking disabled
- No vehicle or personal data ever leaves your device

## Optional network use

The **Check for updates** feature (in Settings and the `autodiag updates`
command-line tool) makes a single HTTPS request to the public GitHub API to
compare the installed version against published releases. This request
contains no personal data.
